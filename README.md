# mt

Manager Table - Go 语言表格管理服务框架。

## 项目简介

mt 是一个高性能的 Go 语言表格管理服务框架，专门用于游戏服务器中的配置数据管理。该框架提供了一套完整的解决方案，包括数据加载、缓存管理、热更新和高效查询等功能。

## 核心特性

- **自动注册机制**: 通过 `init()` 函数自动注册所有表格管理器
- **智能缓存系统**: 使用 ARC 算法的 gcache 实现高效内存缓存
- **实时热更新**: 基于 etcd 的配置监听机制，支持无停机数据更新
- **数据一致性保障**: 通过 CRC32 校验确保配置数据完整性
- **高性能序列化**: 采用 Protocol Buffers 进行数据序列化和反序列化
- **并发安全保障**: 使用原子操作和线程安全的数据结构
- **丰富的查询接口**: 提供多种维度的数据查询方法

## 数据处理流程

### 启动流程
1. **数据加载**: 从 MySQL 数据库读取所有配置表数据
2. **服务注册**: 通过 `init()` 函数自动注册所有表格管理器
3. **内存初始化**: 将数据加载到各管理器的原子指针中
4. **监听启动**: 启动 etcd 配置变更监听协程

### 更新流程
1. **变更检测**: etcd 监听到配置索引变更
2. **CRC 验证**: 对比本地 CRC 与远程 CRC
3. **差异识别**: 筛选出需要更新的表格
4. **数据同步**: 从数据库获取最新数据
5. **缓存清理**: 清除相关查询缓存
6. **内存更新**: 原子更新表格数据

### 查询流程
1. **缓存查找**: 优先从 gcache 查找结果
2. **内存检索**: 缓存未命中时从原子指针获取
3. **结果缓存**: 将查询结果存入缓存
4. **返回数据**: 提供最终查询结果

## 性能优化策略

### 缓存机制
- **算法选择**: 使用 ARC (Adaptive Replacement Cache) 自适应替换算法
- **容量配置**: 默认缓存 2000 个条目，可根据需求调整
- **键值设计**: 采用 `tableName:methodName:params` 格式生成缓存键

### 并发控制
- **读写分离**: 原子指针确保读操作无锁
- **内存安全**: 所有数据访问都是线程安全的
- **批量操作**: 支持批量数据处理提高效率

### 内存管理
- **指针存储**: 使用指针避免大数据结构的拷贝
- **及时释放**: 更新时自动清理过期缓存
- **监控告警**: 建议监控内存使用情况
